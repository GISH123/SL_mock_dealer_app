### Test Limitation

`run_all_tests.py` includes integration tests that may connect to company internal development services, such as FM / DVR targets.

When building on a local internet-enabled computer outside the company internal network, these integration tests may fail. For this Python 3.11.13 handoff task, integration test failure is **not** treated as the final gate.

Current final validation gate:

1. Python 3.11.13 environment can be created
2. Dependencies can be installed
3. PyInstaller can build executables successfully
4. Main GUI executable can start on the local build machine
5. Executables can be copied to the offline remote computer
6. Main GUI executable can start on the offline remote computer

## 6. Known Notes

- The remote test computer has no internet access.
- Do not run `conda create` or `pip install` on the offline remote computer.
- Build executables on the local internet-enabled PC, then copy the release folder to the offline remote computer.
- `run_all_tests.py` is not the final gate for this handoff because integration tests may require company internal development network services.
- `setuptools==81.0.0` is required because `setuptools>=82` no longer provides `pkg_resources`, which may break PyInstaller startup.
- If the `static/` folder is restored, re-run `python post_build.py` so it can be copied into `dist/`.
